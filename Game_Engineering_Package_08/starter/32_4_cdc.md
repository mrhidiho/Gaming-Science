# Learner task: bundled-data CDC model
Model source and destination clocks as independent event schedules. The source latches data, toggles a request and holds data until a synchronized acknowledgement returns. The destination detects a new request, waits according to a declared settling contract, captures exactly once and returns the request state as acknowledgement. Permit only one outstanding word.
Vary clock ratios/phases and abstract synchronizer latency. Test a pulse that is missed, then the handshake remedy. Specify reset ordering and how both endpoints resynchronize; do not reset just one toggle endpoint without a recovery protocol. This is a digital protocol model, not a metastability or physical bundled-data timing proof. Submit your model, traces and CDC_RESET_REVIEW.
