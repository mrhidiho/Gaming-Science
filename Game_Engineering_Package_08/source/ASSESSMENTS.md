# Assessments
## Instructions and scoring
There are 100 questions: 60 unchanged core questions and 40 new transfer questions. IDs ending C1-C3 are original core questions; T1-T2 are added application questions. Each question is worth two points.

Attempt answers before opening the key. For the core quiz, two points requires a correct answer with the reasoning or units appropriate to the question; one point is substantially correct but incomplete; zero is missing or incorrect. Target at least 5/6 per lesson. Transfer questions form a separate /4 diagnostic, with a suggested target of 3/4. They do not replace the original core requirement.

Record explanations in a separate notebook or in the browser edition. Passing a quiz alone does not pass a lesson: the assigned reading and practical assignment must also be complete. Keep first and corrected attempts so that improvements are visible.
