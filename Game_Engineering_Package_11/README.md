**Graduate Gaming Hardware and Research Thesis**

Open `START_HERE.html` for the offline reading entry point, `START_HERE.md` for editable instructions, or `pdf/START_HERE.pdf` for the print guide. This bundle expands Modules 46–50 without renumbering the original curriculum.

The six PDFs contain the student handbook, lab workbook, separate answer key, Gate J thesis/defense/handoff guide, math/reference guide and quick start. Twenty numbered lessons have twenty practical labs and sixty quiz questions with explanations. Five module projects integrate the work; Gate J is one primary thesis rather than an extra collection of capstones.

`source/` and `curriculum.json` are editable. `browser/` is a local reader with lesson search and read tracking. `templates/` contains research and review records to complete. `code/` contains reference models, tests, eight unfinished student functions and optional RTL/formal/physical-flow inputs. `examples/` contains synthetic teaching results, not measured hardware or completed thesis research.

Read `code/README.md` before executing and `validation/VALIDATION_REPORT.md` before interpreting any result. To check release integrity from the package root:
