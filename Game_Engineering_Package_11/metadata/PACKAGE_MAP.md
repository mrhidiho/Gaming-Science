# Package map

`START_HERE.html`, `START_HERE.md`, `pdf/START_HERE.pdf`: entry points.

`pdf/`: six print documents. `source/`: editable teaching text and twenty individual lessons. `curriculum.json`: full structured lesson data. `browser/`: offline reading pages, stylesheet and search/read-tracking code.

`code/`: reference models, student function stubs, regression tests, C++ publication example, optional RTL/formal/EDA inputs and environment reporting. `examples/`: thirteen regenerated synthetic demonstration files. `templates/`: learner-filled evidence, proposal, experiment, review and handoff records.

`metadata/`: continuity, original volume excerpt, reference directories, quiz bank, transfer problems and summary. `validation/`: actual logs and test boundaries. `FILE_MANIFEST.json` and `VALIDATE_PACKAGE.py`: release integrity checks. `NOTICE.md`: scope and rights notice.

No embedded archive is needed to reach the code, templates or sources. Keep your own work outside the untouched release; a hash mismatch after an edit is expected.
