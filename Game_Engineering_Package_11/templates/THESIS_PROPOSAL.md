# Thesis proposal — 3–5-page planning target

Title / author / revision / reviewer: [enter]

## Question and falsifiable hypothesis
Define subject, intervention, comparison, workload population, primary outcome and conditions. State an observation that would weaken or refute the claim.

## Closest work and contribution boundary
Map 8–15 relevant starting sources. Separate established findings, reproduced methods, the proposed extension and speculation.

## Baseline and feasibility
Name the exact baseline revision, invocation, correctness oracle, actual small-case result and evidence path. A planned installation is not a running baseline.

## Method and evaluation contract
Specify primary metric and aggregation, independent unit, pairing/randomization, repetitions, adverse cases, ablation, sensitivity, exclusions and deviations process.

## Scope, resources and risks
Record tools/libraries and rights, time/memory/storage needs, explicit exclusions, risk triggers and the smaller fallback.

## Review decision
Reviewer restatement; decision; blocking repairs; owners/dates; revised scope; approved protocol revision. Leave unreviewed until an actual review occurs.
