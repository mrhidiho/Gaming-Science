# Templates

Copy these files into your own project and fill them with evidence. They are not completed reviews or passing submissions. The evidence-entry template deliberately contains placeholders and will not pass the auditor until replaced with actual paths, supported fields and hashes. Keep ledger artifacts within its directory tree.

Start with REQUIREMENTS_TRACEABILITY and INTERFACE_CONTRACT. Use BENCHMARK_PROTOCOL before collecting data, EXPERIMENT_LOG during the run and DESIGN_REVIEW after an independent reproduction. BOARD_REVIEW is not permission to fabricate or power a circuit. GATE_H_PORTFOLIO follows the full capstone specification.
