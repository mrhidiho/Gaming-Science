# Data provenance

The two CSVs in this folder are **synthetic teaching values**, not measured device or player records.

- `synthetic_frame_times.csv`: nineteen chosen values of 5 ms and one of 100 ms, to expose mean/tail differences.
- `synthetic_regression.csv`: four training and two held-out fictional observations, with predictor/response units deliberately abstract.

The numerical reference outputs in `capstone/reference_evidence/numerics` are generated by explicit mathematical models.
The files in `capstone/reference_evidence/measured_benchmark` are actual measurements of the supplied Python microbenchmark in the recorded creation environment. They do not represent the learner's computer, a GPU, or a game engine.

Do not combine synthetic and measured rows into one supposedly observed dataset. Keep raw data, metadata, and the analysis command together.
