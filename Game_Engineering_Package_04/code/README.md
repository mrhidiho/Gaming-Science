# Code workspaces

`reference/` contains complete demonstrations; `starter/` contains intentionally unfinished student work. The matching `.md` file describes each full lab. `include/` contains educational reference support; it is not a shortcut for implementing the central student algorithms. `c_bridge/` contains actual C sources and C++ callers; `fixtures/` contains inspect-only/broken diagnostic inputs, never part of the default build.

Run the root START_NEXT.pdf commands. The default CMake build registers24 reference test programs. Enable P4_BUILD_STUDENT to build the20 initial student contracts; initially all20 fail with TODO. Keep the full lab's additional cases and transfer requirements.

No compiled binaries are bundled. All programs use standard-library facilities. They have deliberately limited domains; read header contracts and CPP_REFERENCE.pdf before reuse.
