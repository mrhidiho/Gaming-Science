## Browser progress

Lesson status requires the assigned-study box, lab-pass box and a score of at least 5/6. This records your assessment; it does not independently verify mastery. Data stays in the local browser and is not transmitted. Local-file persistence differs between browsers and moving the file may change the storage context. Export progress regularly. Import replaces progress only after confirmation. Printed HTML omits answer panels; use the answer-key PDF when needed.

## Starting today

Extract this entire package. Follow START_HERE for the two-hour option. Python is the only language tool needed at the beginning, and paper tracing can start before installation. Do not begin by installing a commercial engine, GPU SDK or FPGA toolchain.

## Workload and level

The full dual-breadth program is estimated at 4,500–7,200 hours, including exercises, labs, projects and one thesis. These are planning assumptions, not university credits. Lessons are multi-session study units, not 200 short lectures that replace a degree. Required external readings and sustained implementation provide the depth. The program is not accredited, does not award a degree and has not been validated as a university curriculum. Independent review is especially important for advanced mathematics, hardware and thesis work.

## Starter validation

These checks apply to the supplied starter code only, not to the 200 proposed lab implementations or the learner's changes. No compiled binaries are included.
