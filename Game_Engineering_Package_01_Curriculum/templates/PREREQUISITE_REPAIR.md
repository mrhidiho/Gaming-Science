# Prerequisite repair plan

Target lesson or gate:
Missing concept demonstrated by which error?

## Return point
Earlier lesson, reference chapter and assigned exercise.

## Focused practice
One tiny worked example, three new cases and one explanation without notes.

## Transfer test
Apply the idea to a different problem without the old solution.

## Exit criterion
Pass the repaired lesson lab and a new quiz variation, then resume the blocked work. Record evidence and reviewer feedback.
