# Asset provenance

All assets in this folder are original procedural teaching data authored for Package 06. No third-party game assets, logos, commercial models or external textures are used. The mesh is four triangles: a receding plane, an overlapping triangle and a near-plane-crossing triangle. Units are nominal meters in a right-handed view space looking down -Z. Vertex color values are linear sRGB. The checker source is RGB8 sRGB-coded data. The world JSON is an independent schema-migration fixture; it is not automatically instantiated by the CPU renderer.
