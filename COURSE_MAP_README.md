# Student course map

Open [`index.html`](index.html) in a current desktop or mobile browser. The course map works offline and does not need an account, server, or installation. Keep the `Game_Engineering_Package_*` folders next to `index.html`; the map opens each lesson from its original volume reader.

## Find your way through the series

- Search lesson titles, learning outcomes, assigned work, module projects, and prerequisites from the left panel.
- Open a volume to see its modules and lessons, or use the volume cards for quick-start guides, handbooks, labs, and checkpoint briefs.
- Choose a lesson to read it inside the map. Use **Open full reader** when you want the volume reader in its own tab.
- Save lessons with the star button. **Continue** returns to the last lesson opened from this map.
- Answer keys are tucked under each volume's materials. Try the questions before opening them.

The map stores its last lesson and saved lessons in this browser. Individual volume readers have their own progress controls; their export and import options vary, and those records do not sync with this map. If browser storage is disabled for local files, searching and opening lessons still work for the current session.

This is a self-study program. The 4,500–7,200 hour total is a planning estimate, not academic credit. The checkpoint cards are project requirements for learners to complete, not claims that the projects have already been built.
